A **code editor** is a text editor designed for writing code. That's it. It opens files. It shows them in a window. You type. You save.

What makes a *code* editor different from, say, the Notes app:

- **Syntax highlighting** — keywords are colored so you can read code at a glance.
- **File tree** — a sidebar showing all the files in your project.
- **Search across files** — find a string anywhere in the project.
- **Extensions** — add features (Git, Docker, language support) without changing the editor itself.
- **Integrated terminal** — run commands without leaving the editor window.

You've probably seen one before, even if you didn't know its name. VS Code, Sublime Text, Vim, IntelliJ — all editors. Some are minimal; some come loaded with tooling for specific languages.

**Cursor is a code editor.** A particular kind, which we'll get to next. But underneath the AI features, it's still doing the same job: opening files and letting you type.
