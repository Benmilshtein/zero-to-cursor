The first time you open Cursor, you'll see a **welcome / get-started** screen. Don't let it overwhelm you. You're going to ignore most of it.

You'll typically be offered:

- **Import from VS Code** — bring over your extensions, settings, themes, keybindings.
- **Sign in** — link the desktop app to your Cursor account (we covered this).
- **Pick a theme** — light, dark, high contrast.
- **Pick a keybinding scheme** — VS Code, Vim, Emacs, Atom, Sublime.
- **Open a project / clone from Git / create new file**.

### What to do right now

1. **Sign in** if you haven't already.
2. **Pick the dark theme** (or whatever you prefer; it has no effect on learning).
3. **Skip "Import from VS Code"** for now — even if you're a VS Code user. Learn Cursor on a clean slate first; you can import later.
4. **Don't open a project yet.** We'll do that in the next lesson, deliberately.

If Cursor prompts you about telemetry or analytics, that's fine to opt out of — it doesn't affect the editor's functionality.

When you've done that, you should be staring at an empty editor. That's the goal. Empty editor, sidebar visible on the left, a welcome tab still open. Ready.
