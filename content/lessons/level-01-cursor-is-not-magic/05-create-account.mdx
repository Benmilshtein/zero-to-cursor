Cursor uses an account to track which AI features you're using and against which plan. You can use the editor without one in a limited way, but the AI features all want to know who you are.

When you first launch Cursor, you'll be prompted to **Sign In or Sign Up**. The flow opens a browser, you authenticate (Google, GitHub, email), and the browser hands you back to the desktop app.

### Plans (as of writing)

- **Hobby (free)** — Limited Cursor Tab completions, limited slow requests to Cursor's AI models. Enough for casual use and the early parts of this course.
- **Pro** — Higher limits, faster requests, access to more powerful models.
- **Business / Enterprise** — Team management, privacy mode, audit logs.

For the entire first half of this course (Levels 1–6), the **free plan is enough**. By the time you get to Composer and Agent (Levels 7–8), you'll get more value if you upgrade — but you don't have to.

### Privacy mode

In Cursor's settings, **Privacy Mode** controls whether your code can be retained or used for training. Default it on if you work on anything proprietary. Many companies require it.
