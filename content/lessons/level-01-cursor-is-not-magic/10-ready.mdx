You now know:

- What a code editor is, and what makes Cursor an AI-first one.
- That Cursor is a fork of VS Code — your shortcuts and extensions mostly transfer.
- How to install Cursor on any OS, sign in, and create your first project.
- The five regions of the Cursor window, including the AI pane on the right.
- The four AI primitives — Tab, Cmd+K, Chat, Agent — and the order we'll learn them.

That's Level 1. You haven't written any code with the AI yet. That's deliberate. The next thirteen levels are where the muscle memory builds:

| Level | What you'll learn |
| --- | --- |
| **2** | Working in Cursor day-to-day — the command palette, settings, themes. |
| **3** | **Cursor Tab** — how to accept, partial-accept, multi-line, when to reject. |
| **4** | **Cmd+K** — inline edits, refactors, and prompt patterns. |
| **5** | **The Chat panel** — @-mentions, asking about your code. |
| **6** | **Codebase awareness** — `@Codebase`, indexing, `.cursorignore`. |
| **7** | **Composer** — multi-file changes with confidence. |
| **8** | **Agent mode** — autonomous coding with guardrails. |
| **9** | **Rules** — `.cursorrules` to teach Cursor your project's style. |
| **10** | **MCP** — connecting Cursor to external tools. |
| **11** | **Context mastery** — every `@` symbol, when to use which. |
| **12** | **Advanced** — background agents, Bug Bot, model selection. |
| **13** | **Junior developer patterns** — debugging, deployment, real workflows. |
| **14** | **The capstone** — ship a real, small app end-to-end. |

When you're ready, head to **Level 2**. Or take a break — your progress is saved.
