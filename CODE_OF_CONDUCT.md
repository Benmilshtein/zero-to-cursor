# Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity, level of experience, nationality, race, religion, or sexual orientation.

## Standards

- Be respectful in PRs, issues, and discussions.
- Assume good intent; ask before assuming bad.
- Keep technical disagreements technical.
- Public shaming, harassment, or doxxing of contributors gets you removed.

## Enforcement

Report issues to the project maintainers via GitHub issue (or email if listed in the repo). All reports are confidential. Maintainers will respond and act proportionately — warning, temporary ban, or permanent ban.

This document is adapted from the Contributor Covenant 2.1.
