## Level 1 — Cursor Is Not Magic (✓ shipped)

The premise: zero assumptions. By the end, the reader knows what Cursor is, how it differs from VS Code, how to install it, sign in, and identify the parts of the window.

1. What is a code editor?
2. What makes Cursor different
3. Cursor vs VS Code
4. Installing Cursor
5. Creating your Cursor account
6. First launch — the welcome screen
7. Opening your first project
8. The Cursor interface — a guided tour
9. The four AI primitives you'll learn
10. You're ready — what's next

## Level 2 — Your First 30 Minutes in Cursor (planned)

Daily-driving Cursor without AI yet: command palette, settings, themes, keybindings, the integrated terminal. By the end the reader can navigate Cursor as confidently as VS Code.

Suggested lessons:
- The command palette (Cmd+Shift+P)
- File switching (Cmd+P)
- Settings — UI vs JSON
- Picking a theme and font
- Keybindings — finding and changing
- The integrated terminal
- Multi-cursor and selection
- Find and replace, across files
- Source control (Git) view
- Extensions marketplace
- Welcome back — recap

## Level 3 — Tab Completion (planned)

The reader's first AI interaction. Tab predicts; learn when to accept, partial-accept, and reject.

## Level 4 — Inline Edits with Cmd+K (planned)

Selection-driven edits. Patterns that work, patterns that don't.

## Level 5 — The AI Chat Sidebar (planned)

Conversational AI with @-mentions. When to chat vs Cmd+K.

## Level 6 — Codebase Awareness (planned)

`@Codebase`, indexing, `.cursorignore`. How Cursor "knows" your project.

## Level 7 — Composer & Multi-file Edits (planned)

Beyond single-file: planning, applying, reverting multi-file changes safely.

## Level 8 — Agent Mode — Autonomous Coding (planned)

Tools, terminal access, approvals. What to trust the agent with.

## Level 9 — Rules — Teaching Cursor Your Style (planned)

`.cursorrules` and `.cursor/rules/*.mdc`. How to scope rules. Anti-patterns.

## Level 10 — MCP — Connect Cursor to Everything (planned)

Installing MCP servers. Useful real-world servers. Custom servers.

## Level 11 — Context Mastery (planned)

Every `@` symbol — Files, Folders, Docs, Web, Git, Definitions. When to use which.

## Level 12 — Cursor Advanced (planned)

Background agents, Bug Bot, PR review, model selection, cost.

## Level 13 — Junior Developer Patterns (planned)

Real workflows: debugging with AI, deployment, code review, working with teams.

## Level 14 — The Project — Ship a Real App (planned)

A capstone. Probably a small full-stack app (TBD). The reader builds it with the Agent, deploys it.

---

## How target lesson counts can change

These numbers are starting points. If a contributor argues a level needs 15 lessons instead of 10, and the lessons are good, that's fine. If a level can be done in 6, that's fine too.

The goal isn't 147 lessons. The goal is to teach Cursor end-to-end at the right level of resolution.
